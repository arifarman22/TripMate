# TripMate Analytics Features

## Implemented Features

### 1. Expense Statistics Dashboard
Displays 4 key metrics:
- Total Spent
- Total Expenses  
- Average Expense
- Top Category

### 2. Category Breakdown (Pie Chart)
- Visual breakdown by category
- Recharts PieChart
- Color-coded with percentages
- Interactive tooltips

### 3. User Contributions (Bar Chart)
- Compares paid vs owed
- Side-by-side bars
- Blue = Paid, Green = Owed
- Auto-calculates balance

### 4. Dynamic Updates
Charts update automatically when expenses are added.

## Usage
1. Navigate to trip
2. Click Analytics tab
3. View charts
4. Add expense to see updates
